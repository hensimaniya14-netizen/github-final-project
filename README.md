# Simple Interest Calculator

A simple script to calculate the simple interest based on the principal amount, rate of interest, and time period.

## Formula
The formula used to calculate simple interest is:
`Simple Interest (SI) = (P * R * T) / 100`

Where:
- **P** = Principal amount (Initial money invested or loaned)
- **R** = Annual rate of interest (in percentage)
- **T** = Time period (in years)

## Example Calculation
If you invest **$1000** at an annual interest rate of **5%** for **2 years**:
- `P = 1000`
- `R = 5`
- `T = 2`

**Calculation:**
`SI = (1000 * 5 * 2) / 100 = 100`

- **Total Interest:** $100
- **Total Amount (Principal + Interest):** $1100
